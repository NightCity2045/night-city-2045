

# GDD: Хардкорная многослойная система брони

## 1. Концепция и Видение

Мы полностью отказываемся от ванильной аркадной системы SS14, где броня снижает входящий урон на определенный процент. Новая система работает на строгой физической логике **«Пробитие vs Класс Защиты»**. Броня не смягчает пулю — она либо останавливает её полностью, спасая тело, либо прошивается насквозь, передавая весь урон в плоть (вызывая ранения и кровотечения по нашей мед. системе).

Каждый бронежилет является «композитным» предметом, состоящим из нескольких физических слоев с независимым запасом прочности и зонами покрытия.

## 2. Основные механики: Слои и Характеристики

Любая пуля/снаряд в игре теперь обязана иметь параметр **`Penetration`** (Пробиваемость, от 1 до 6+).
Броня использует параметр **`ArmorClass`** (Класс защиты, от 0 до 6+).
Если `Penetration` $\ge$ `ArmorClass` — броня пробита.

Броня разделена на два неразделимых (вшитых) слоя:

1. **Soft Layer (Мягкий слой / Разгрузка / Чехол):**
* Основа бронежилета.
* Имеет широкую зону покрытия (например, Торс + Руки).
* Чаще всего имеет `ArmorClass = 0` (не останавливает пули).


2. **Hard Layer (Твердый слой / Бронеплиты):**
* Тяжелые стальные, керамические или титановые вставки.
* Имеют узкую зону покрытия (только Торс).
* Имеют высокий `ArmorClass` (например, 4 или 5).

## 3. Алгоритм расчета попадания (Hit Calculation Flow)

Когда пуля (снаряд) попадает в сущность игрока, система `ArmorSystem` выполняет следующие проверки строго по порядку (снаружи внутрь):

### Шаг 1: Определение зоны попадания

Система прицеливания выдает конкретную зону (хитбокс), куда пришлась пуля. Например: `LeftArm` (Левая рука) или `Torso` (Грудь). Shitmed

### Шаг 2: Проверка Soft Layer (Внешний слой)

Пуля всегда сначала контактирует с чехлом.

* Система проверяет, защищает ли `soft_layer` эту зону.
* Если **ДА**: происходит сравнение пробития. Так как обычно `Penetration` пули больше, чем `ArmorClass` ткани, пуля проходит насквозь. `soft_layer` получает урон по параметру `Durability` (прочность ткани снижается — появляется дырка).

### Шаг 3: Проверка Hard Layer (Внутренний слой)

Пуля летит дальше и проверяет наличие плиты.

* Система проверяет, защищает ли `hard_layer` текущую зону.
* Если **НЕТ** (например, попадание в `LeftArm`, а плиты только на `Chest`): пуля беспрепятственно входит в тело. Игрок получает полный урон, ранение конечности и кровотечение.
* Если **ДА** (попадание пришлось в `Chest`): начинается математика пробития.
* **Сценарий А (Плита выдержала):** `Penetration` пули **МЕНЬШЕ**, чем `ArmorClass` плиты. Пуля остановлена. Игрок **получает** урон по телу, но не penetration, а blunt. Плита (`hard_layer`) получает урон по `Durability` от кинетического удара.
* **Сценарий Б (Пробитие):** `Penetration` пули **РАВЕН** `ArmorClass` плиты. Бронебойная пуля прошивает сталь. Плита теряет `Durability`, пуля уходит в тело, игрок получает половину урон и ранение.
* **Сценарий В (Полное Пробитие):** `Penetration` пули **БОЛЬШЕ** `ArmorClass` плиты. Бронебойная пуля прошивает сталь. Плита теряет `Durability`, пуля уходит в тело, игрок получает плолный урон и ранени

## 4. Механика разрушения (Armor Degradation)

Броня не вечна. Потеря прочности (`Durability`) приводит к критическим последствиям для защиты.

* **Разрушение Плит (Hard Layer = 0 HP):**
Если плиты приняли слишком много попаданий и их прочность упала до нуля, они разрушаются внутри чехла.
* *Последствие:* `ArmorClass` компонента `hard_layer` принудительно становится равен `0`. Следующая пуля в грудь пройдет насквозь в тело. При этом сам бронежилет остается на игроке.


* **Разрушение Разгрузки (Soft Layer = 0 HP):**
Чехол порван в клочья от множественных попаданий. Плиты больше не в чем держать, они вываливаются или смещаются.
* *Последствие:* Это критическая поломка всего предмета. Если `soft_layer` достигает 0 HP, параметры `ArmorClass` **ОБОИХ** слоев (и софта, и харда) навсегда падают до `0`. Бронежилет превращается в бесполезные лохмотья.

## 5. Техническая реализация (Для разработчиков)

### Архитектура ECS

Необходимо создать новый компонент `LayeredArmorComponent`, который заменит ванильный `ArmorComponent`.

Структура данных (C# заготовка):

```csharp
[RegisterComponent]
public sealed class LayeredArmorComponent : Component
{
    [DataField("softLayer")]
    public ArmorLayer SoftLayer { get; set; } = new();

    [DataField("hardLayer")]
    public ArmorLayer HardLayer { get; set; } = new();
}

[DataDefinition]
public sealed class ArmorLayer
{
    [DataField("armorClass")]
    public int ArmorClass = 0;

    [DataField("maxDurability")]
    public float MaxDurability = 100f;

    [DataField("currentDurability")]
    public float CurrentDurability = 100f;

    [DataField("coverageZones")]
    public List<TargetZone> CoverageZones = new();
}

```

### Пример прототипа бронежилета (YAML)

Вот как геймдизайнер будет настраивать броню в файлах:

```yaml
- type: entity
  id: ClothingOuterArmorVest
  name: бронежилет
  description: Надежная разгрузка со вшитыми стальными плитами. Тяжелая, но спасет от пули.
  parent: ClothingOuterBase
  components:
  - type: LayeredArmor
    softLayer:
      armorClass: 0       # Пробивается чем угодно
      maxDurability: 100  # Выдержит ~5-7 пробитий до полного уничтожения
      currentDurability: 100
      coverageZones:
      - Torso
      - LeftArm
      - RightArm
    hardLayer:
      armorClass: 4       # Останавливает пистолеты и легкие ПП (Penetration 1-3)
      maxDurability: 250  # Сталь держит много ударов
      currentDurability: 250
      coverageZones:
      - Torso

```

### Интеграция с UI (Осмотр брони)

При использовании инструмента "Осмотр" (Examine) на бронежилете, игроку не должны писаться точные цифры HP. Выводим текст в зависимости от состояния `Durability`:

* > 80%: *"Бронежилет в отличном состоянии."*


* 30% - 80%: *"На ткани видны пулевые отверстия, плиты внутри помяты."*
* < 30%: *"Разгрузка держится на честном слове, плиты покрошились."*
* `soft_layer` = 0: *"Это просто кусок рваной ткани со звонким мусором внутри."*
